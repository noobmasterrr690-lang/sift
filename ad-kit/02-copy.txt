---------- KEY FEATURES (source of truth, from the app) ----------

1. TIDY UP: Sorts loose files into folders by type, right where they
   already are: Images (by year/month), Documents, Design files
   (PSD, AI, FIG...), Videos, Audio, Archives, Installers, Fonts,
   3D Models, E-books, Code & Data.
2. CLEAN UP: Finds unfinished downloads, exact duplicates, old
   installers, old screenshots, and large files you haven't touched.
   Sends them to the Recycle Bin only, so nothing is ever permanently
   deleted.
3. HISTORY & 1-CLICK UNDO: Every sort is logged, and one click puts
   every file back exactly where it was.
4. SAFETY: Never overwrites anything. Name clashes get a (1), (2) suffix.
5. NATIVE & LOCAL: A Windows desktop app. Your files never leave your PC.
